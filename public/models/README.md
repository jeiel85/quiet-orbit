# public/models

3D 모델(GLB) 정적 에셋 폴더. Vercel 에서 `/models/...` 경로로 그대로 제공됩니다.

- **현재(MVP)**: 비어 있음. 행성·플레이어·장식은 모두 primitive geometry 로 구현하며 외부 모델을 쓰지 않습니다.
- **후속**: GLB 모델을 여기에 두고 `useGLTF("/models/...")` 로 로드합니다.

## 규칙

- 포맷: `.glb` (용량이 클 때만 Draco 압축)
- 브라우저 캐시 무효화를 위해 파일명에 버전을 포함: `player-v001.glb`
- 모바일 성능을 위해 폴리곤 수와 애니메이션 클립 수를 최소화
