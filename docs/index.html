Quiet Orbit

작은 행성을 천천히 걷다가, 빛나는 메시지 하나를 발견하는 곳.

GitHub에서 보기 설계 문서 읽기

무엇인가요

Quiet Orbit은 경쟁도 점수도 없는 조용한 3D 웹 산책입니다. 작은 구형 행성 위를 걸으며 곳곳에 놓인 빛나는 메시지 조각(Orb)에 다가가 짧은 글을 읽습니다. 1분 남짓 머물며 따뜻한 흔적을 발견하고 떠나는 경험을 지향합니다.

🌍 작은 행성 산책

구면 위를 부드럽게 이동하고, 3인칭 카메라가 천천히 따라옵니다.

✨ 빛나는 메시지

행성 곳곳의 Orb에 가까이 가면 짧은 메시지를 열어볼 수 있습니다.

📱 모바일 & 데스크톱

키보드와 터치 조이스틱을 모두 지원하는 가벼운 반응형 경험.

🔒 계정 없이

로그인도 서버도 없이, 읽은 메시지는 브라우저에 조용히 저장됩니다.

기술

Next.js (App Router) · TypeScript · Three.js · React Three Fiber · drei · zustand · Tailwind CSS · Vercel 배포를 목표로 합니다.

✅ MVP 기능 완성 — 행성 산책·메시지 열람·읽음 저장·모바일 조작까지 구현했습니다. 지금은 저장소를 받아 npm run dev 로 로컬에서 실행할 수 있고, 플레이 가능한 라이브 데모는 배포 후 이곳에 연결할 예정입니다.

고품질 브라우저 3D 경험에서 감성적 구조만 벤치마킹한 독립 프로젝트입니다. 특정 사이트의 브랜드·캐릭터·에셋·맵·텍스트를 복제하지 않습니다.
